# antigravity远程-mogu · 远程会话规则

本工作区接入了「antigravity远程-mogu」：微信 / QQ / 飞书 的私聊消息会被桥接到这里执行。

## 当消息来自远程 IM 时

当用户消息来自手机聊天窗口时（桥接层会记录来源，提示词里不再插入标记），按下面的方式处理：

1. **产出文件要主动回传**：当你生成了用户可能需要的文件（报告、图片、压缩包、导出文档），调用 MCP 工具 `remote_send_file`，把原文件发回该聊天。不要只说"文件已生成在 xxx"。
2. **简短优先**：手机屏幕小，先给结论再给细节；超过 1500 字的说明拆成分点。
3. **图片回传**：截图、生成的图直接 `remote_send_file`（会自动按图片气泡发送）。
4. **不要重复播报**：桥接层已经把过程实时推给用户，最终回复只讲结果与下一步。
5. **需要用户确认的危险操作**：桥接层会自动把审批按钮转成手机上的交互卡片，正常发起即可，无需额外说明。
6. **先读附件再回答**：如果消息末尾带“本机附件，可直接读取：...”，那是桥接层刚下载到本机的图片/文件绝对路径。必须先实际读取这些路径（图片按图片读取，文档按类型读取），再回答；不要只根据“收到一张图片/文件”的占位文字猜测内容。

## 可用的 MCP 工具

- `remote_send_file`：把本地文件发回指定聊天（参数：`target`、`path`、可选 `caption`）
- `remote_send_message`：给指定聊天发一条文本（参数：`target`、`text`）
- `remote_list_targets`：列出当前可用的聊天目标（绑定关系与最近活跃会话）

`target` 可以写绑定 ID、`平台:chat_id`，或者直接写 `last`（最近一条来自远程的消息来源）。
